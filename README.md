# University Management System

A desktop application for managing core university operations — students, lecturers, courses, departments, and enrollments — built with **Java Swing** (MVC architecture) and a **MySQL** backend. Developed as a NetBeans project.

## Features

* **User Authentication** — Login and registration (`LoginForm`, `RegisterForm`)
* **Student Management** — Add, update, view, and remove student records
* **Lecturer Management** — Manage lecturer profiles and assignments
* **Course Management** — Create and maintain course listings
* **Department Management** — Organize courses and staff by department
* **Enrollment Management** — Enroll students into courses and track enrollment records
* **Dashboard** — At-a-glance overview of system data
* **Reports** — PDF report generation using JasperReports, including:

  * Department Course \& Enrollment Summary
  * Department Financial Overview
  * Student Enrollment \& Demographics Report

## Tech Stack

* **Language:** Java 24
* **UI:** Java Swing (NetBeans GUI Builder — `.form` files)
* **Architecture:** MVC (`model` / `view` / `controller` / `dao`)
* **Database:** MySQL (via `mysql-connector-j`)
* **Reporting:** JasperReports, iText
* **Build tool:** Apache Ant (NetBeans default)

## Project Structure

```
UniversityManagementSystem/
├── src/
│   ├── controller/     # Business logic linking views to DAOs
│   ├── dao/            # Data access objects (JDBC/SQL)
│   ├── db/             # DBConnection (singleton MySQL connection)
│   ├── model/           # Plain Java objects (Student, Lecturer, Course, etc.)
│   ├── view/            # Swing forms (.java + .form)
│   ├── reports/          # JasperReports (.jrxml) templates and generator
│   ├── images/           # UI icons/images
│   └── universitymanagementsystem/  # Main class (entry point)
├── lib/                 # Third-party JAR dependencies
├── build.xml             # Ant build script
├── nbproject/            # NetBeans project configuration
└── dist/                 # Compiled JAR output (generated by build)
```

## Prerequisites

* **JDK 24** (or update `javac.source` / `javac.target` in `nbproject/project.properties` to match your installed JDK)
* **MySQL Server** (running locally, default port `3306`)
* **NetBeans IDE** (recommended) or Apache Ant for command-line builds

## Database Setup

The application connects to a MySQL database named `university\_db` (see `src/db/DBConnection.java`):

```
URL:      jdbc:mysql://localhost:3306/university\_db
User:     root
Password: (empty by default)
```

1. Create the database:

```sql
   CREATE DATABASE university\_db;
   ```

2. Create the required tables: `users`, `students`, `lecturers`, `courses`, `departments`, `enrollments` (matching the fields used in the classes under `src/model/` and the queries in `src/dao/`).
3. Update the credentials in `src/db/DBConnection.java` if your MySQL setup differs from the defaults above.

> \*\*Note:\*\* No `.sql` schema file is included in this project. You'll need to create the schema based on the model classes, or export/share your own `schema.sql` and add it to the repo for future setup.

## Running the Project

### Option 1 — NetBeans IDE

1. Open the project folder in NetBeans (`File → Open Project`).
2. Ensure the MySQL database is running and configured as above.
3. Right-click the project → **Run**.

### Option 2 — Command line (Ant)

```bash
ant clean build
ant run
```

### Option 3 — Run the packaged JAR

```bash
cd dist
java -jar UniversityManagementSystem.jar
```
